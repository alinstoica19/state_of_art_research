# Feedback-Driven Federated Learning for Distributed NWDAFs in 5G Core (2024)

## Problema (cum o formuleaza autorii)
NWDAF foloseste algoritmi ML pentru a analiza NF-uri din core-ul 5G; incepand cu Release 17 se anticipeaza o arhitectura distribuita cu mai multe componente la edge, pentru procesare paralela si latenta redusa a serviciilor.
## Ce propun (metoda, pe scurt)
Feedback-Driven Federated Learning (FDFL) pentru orchestrarea unei arhitecturi NWDAF distribuite: un mecanism de feedback ghideaza modelele ML ale NWDAF-urilor client spre o convergenta mai rapida catre optimul functiei globale, pastrand confidentialitatea datelor. Introduce Influence-based Weighted Federated Averaging pentru a gestiona influenta parametrilor modelelor NWDAF-urilor edge asupra agregarii globale; recomanda Local Differential Privacy (LDP) pentru mascarea schimbului de parametri.
