# Decentralized Machine Learning based Network Data Analytics for Cognitive Management of Mobile Communication Networks (2022)
Cheie: BD-28 . DOI/link: 10.1109/noms54207.2022.9789936 . Sursa textului: DOAR REZUMAT (OpenAlex/Crossref; IEEE/IFIP NOMS 2022)
Sectiunea din plan: B

## Problema (cum o formuleaza autorii)
NWDAF standardizat in 3GPP permite furnizori terti de servicii de analitica AI; RAN-urile urmatoarei generatii necesita analitica avansata pentru functii SON in bucla inchisa. Solutiile existente folosesc ML conventional cu date acumulate intr-un singur data center, ceea ce ridica probleme de supraincarcare a retelei si de confidentialitate cand operatorii partajeaza date sensibile cu servicii terte (NDAS) pe infrastructura edge.
## Ce propun (metoda, pe scurt)
O abordare bazata pe Federated Learning pentru antrenarea modelelor ML de management cognitiv al retelei, in care operatorii construiesc colaborativ un model comun pastrand datele critice local in domeniile proprii. Lucrarea afirma ca propune si evalueaza abordarea.
