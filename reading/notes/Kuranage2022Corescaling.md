# Deep learning based resource forecasting for 5G core network scaling in Kubernetes environment (2022)

## Problema (cum o formuleaza autorii)
Retelele 5G evolueaza spre cloudificare; scalarea la cerere a network function-urilor este un avantaj al desfasurarii pe containere, iar tiparele de trafic variabile necesita o abordare automata noua de management al resurselor in medii cloud-native; gestionarea resurselor este dificila la scara si complexitatea 5G (rezumat).

## Ce propun (metoda, pe scurt)
O abordare de forecasting al utilizarii resurselor bazata pe deep learning, care furnizeaza informatii pentru deciziile de scalare a containerized Network Functions (CNF) in Kubernetes (rezumat).

## Setup experimental
Din rezumat: un testbed in mediu Kubernetes a fost implementat pentru a genera un dataset apropiat de date reale pentru antrenarea modelelor. Core-ul folosit, scara, UE: nedeclarat (doar rezumat).

Din rezumat: s-a evaluat cel mai bun model de forecasting si s-a comparat cu o alta abordare de forecasting bazata pe deep learning. Metrici: nedeclarat (doar rezumat).
