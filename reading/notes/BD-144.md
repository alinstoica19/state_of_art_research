# A Standards-Compliant Dataset Creation Pipeline for 5G Core: Extending the NWDAF (2026)
Cheie: BD-144 . DOI/link: 10.1109/meditcom67211.2026.11641015 . Sursa textului: DOAR REZUMAT (Semantic Scholar API; text integral inchis, IEEE)
Sectiunea din plan: B . Tema: NWDAF / datasets
## Problema (cum o formuleaza autorii)
Integrarea AI in 5G este ingreunata de lipsa seturilor de date standardizate si reproductibile: operatorii nu partajeaza date proprietare din motive de securitate si competitie, iar testbed-urile de cercetare produc modele de date specializate si neinteroperabile.
## Ce propun (metoda, pe scurt)
Extended NWDAF (XNWDAF): o extensie functionala a serviciului Nnwdaf_Analytics_Info care transforma NWDAF intr-un pipeline de creare de seturi de date conform 3GPP; exporta KPI-uri de retea sanitizate sub forma de fisiere neutre fata de furnizor, in loc de telemetrie bruta; captura parametrii de interogare 3GPP pentru minimizarea datelor si reproductibilitate.
## Setup experimental (testbed real / emulare / simulare; unelte; scara; date)
Proof-of-concept intr-un mediu de laborator 5G, folosind Network Slice Instance Load Level Event (rezumat); unelte, scara: nedeclarat (doar rezumat).
## Experimente si metrici
Seturile generate au fost folosite pentru antrenarea unui model LSTM de predictie a incarcarii CPU (rezumat); alte detalii: nedeclarat (doar rezumat).
## Rezultate raportate (cifre exacte, cu trimitere la tabel/figura)
Loss de test 0.0170 pentru modelul LSTM de predictie a incarcarii CPU (rezumat). Tabele/figuri: nedeclarat (doar rezumat).
