# Beyond NWDAF Services for Comprehensive 5G Network Analytics and Orchestration (2025)
Cheie: BD-159 . DOI/link: 10.1109/cits65975.2025.11099169 . Sursa textului: DOAR REZUMAT (OpenAlex/Crossref; textul integral nu a fost accesat)
Sectiunea din plan: B . Tema: NWDAF extins / observabilitate multi-strat
## Problema (cum o formuleaza autorii)
Rezumatul afirma ca NWDAF este standardizat de 3GPP, dar serviciul de telemetrie ar trebui extins dincolo de core (edge, RAN, chiar UE in retele private), impulsionat de virtualizare; implementarea si extinderea practica raman provocari deschise, mai ales pentru noi functii de analitica a resurselor virtualizate.
## Ce propun (metoda, pe scurt)
Arhitectura NWDAF extinsa bazata pe microservicii, care integreaza evenimentele NWDAF standardizate si trei functii suplimentare de analitica: Container Data Analytics Function (C-DAF), RAN Data Analytics Function (RAN-DAF) si UE Data Analytics Function (UE-DAF). Serviciile colecteaza metrici multi-strat in timp real din 5GC, RAN, UE si infrastructuri cloud/edge. Cadrul ramane conform standardelor 3GPP si imbunatateste monitorizarea end-to-end pentru a sprijini orchestrarea in diferite segmente de retea.
