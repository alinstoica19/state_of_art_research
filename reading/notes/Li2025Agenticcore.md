## Problema (cum o formuleaza autorii)
Complexitatea retelelor 5G este larg comentata, iar 6G se asteapta cu capabilitati extinse. Autorii spun ca, fara un design adecvat, imbogatirea 6G va creste si mai mult complexitatea sistemului.
## Ce propun (metoda, pe scurt)
Agentic-AI Core (A-Core), o arhitectura de core network empowered de AI, orientata pe misiuni, pentru telecomunicatiile mobile de generatie urmatoare. In A-Core, capabilitatile de retea pot fi adaugate si actualizate din mers si programate in misiuni. Misiunile sunt create si executate de agenti de retea autonomi, conform intentiei clientului (care poate fi exprimata in limbaj natural). Agentii transforma intentiile in workflows de capabilitati de retea, folosind un model AI de retea de mari dimensiuni (large-scale network AI model).
