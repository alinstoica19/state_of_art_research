# A Zero Touch Emulation Framework for Network Slicing Management in a 5G Core Testbed (2021)
Cheie: BD-12 . DOI/link: https://doi.org/10.23919/cnsm52442.2021.9615531 . Sursa textului: DOAR REZUMAT (OpenAlex/Crossref/Semantic Scholar; textul integral nu este liber accesibil)

## Problema (cum o formuleaza autorii)
Network slicing ofera eMBB, uRLLC si mMTC prin retele virtuale izolate intr-un mediu NFV. Lucrarea este o demonstratie (rezumat).

## Ce propun (metoda, pe scurt)
Autorii au construit un testbed 5G Core compatibil 3GPP cu network slicing pentru servicii eMBB, uRLLC si mMTC si prezinta in demonstratie un framework zero-touch de management si orchestrare a slicing-ului 5GC intr-un mediu NFV, cu functii 5GC si aplicatii pe slice-uri eMBB si uRLLC; scopul declarat este sa ghideze operatorii in construirea de slice-uri autonome zero-touch cu management si orchestrare in closed loop automation (rezumat).
