## Problema (cum o formuleaza autorii)
Network Fault Prediction (NFP) poate creste fiabilitatea retelei prin mentenanta preventiva si mitigarea defectelor iminente. Autorii mentioneaza perspectiva retelelor "zero-failure" pentru aplicatii critice peste retele heterogene si complexe.

## Structura si taxonomia propusa
Conform rezumatului:
1. conceptele-cheie NFP;
2. constrangerile unui Network and System Integrator (NSI): heterogenitate, QoS, costuri de mentenanta, Time To Restore garantat in functie de importanta echipamentului;
3. o metrica noua de performanta ML, care masoara reducerea asteptata a costului de mentenanta pe baza unui model predictiv;
4. survey al metodelor ML folosite in NFP, cu recomandari pentru retele de telecomunicatii;
5. tipuri de predictii NFP: Equipment Health, Network Health, Link Failure, Alarm Prediction.
