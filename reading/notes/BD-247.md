# Explainable Performance Analysis of Open-Source 5G Core Network Implementations Via Observability (2025)

Sectiunea din plan: B . Tema: benchmark / observabilitate core 5G open-source
## Problema (cum o formuleaza autorii)
Rezumatul afirma ca proiectele open-source au facilitat implementari 5G pe hardware standard, dar maturitatea lor ramane inadecvata pentru implementari 5G de inalta performanta si la scara mare. Testarea performantei 5G adopta in principal perspectiva black-box, care nu surprinde interactiunile dintre componentele core-ului si impiedica identificarea blocajelor; testele sunt adesea la scara mica, iar seturile de date publice din implementari reale sunt rare.
## Ce propun (metoda, pe scurt)
Metodologie de testare a performantei core-ului 5G bazata pe observabilitate, cu vizibilitate asupra interactiunilor interne dintre componente. Contributii enumerate: (i) simularea unor rate variabile de sosire a utilizatorilor, (ii) publicarea unui set de date public cu interactiuni ale componentelor core, loguri si metrici de performanta, (iii) analiza comparativa a doua implementari open-source populare de core 5G.
