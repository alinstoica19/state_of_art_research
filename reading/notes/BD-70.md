# A new framework for failure classification in 5G core network (2024)
Cheie: BD-70 . DOI/link: 10.1109/comnet64071.2024.10987290 (https://doi.org/10.1109/comnet64071.2024.10987290) . Sursa textului: DOAR REZUMAT (abstract din OpenAlex; textul integral nu a fost accesibil liber)

## Problema (cum o formuleaza autorii)
Sistemele 5G bazate pe NFV si SDN au crescut complexitatea, volumul de lucru si incertitudinea operarii si mentenantei; managementul defectelor era facut istoric manual, iar in era 5G dependenta exclusiva de operatori umani nu va fi suficienta. Este nevoie de o abordare automata care sa analizeze milioane de date de retea pentru a detecta, clasifica sau prezice defecte.

## Ce propun (metoda, pe scurt)
Un sistem bazat pe ML pentru detectia si clasificarea autonoma a defectelor din 5G Core Network, plus o analiza comparativa a diferitilor algoritmi de machine learning / deep learning aplicati.
