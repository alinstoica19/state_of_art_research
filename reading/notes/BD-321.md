# Analysis of Network Failure Detection Using Machine Learning in 5G Core Networks (2023)
Cheie: BD-321 . DOI/link: 10.1007/978-981-99-3010-4_5 . Sursa textului: DOAR REZUMAT (pagina Springer link.springer.com/chapter, fara acces la text integral; Lecture Notes in Networks and Systems, ICICC)
Sectiunea din plan: B

## Problema (cum o formuleaza autorii)
Furnizorii de servicii mobile trebuie sa ofere servicii Internet fiabile pentru 5G; deoarece Internetul este operat cooperativ, un defect neasteptat in domeniul unui furnizor se poate propaga rapid, iar doar operatori cu experienta pot trata astfel de defecte. ML este prezentat ca modalitate de tratare a defectelor neasteptate din core, reducand costurile operationale.
## Ce propun (metoda, pe scurt)
Analiza defectelor de retea din core-ul 5G cu ML: se compara trei algoritmi ensemble (XGBoost, LGBM, random forest) din perspective: preprocesarea datelor de antrenare, esantioane normale/anormale si importanta trasaturilor.
