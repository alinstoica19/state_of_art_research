# Network Data Analytics Function for IBN-based Network Slice Lifecycle Management (2021)

## Problema (cum o formuleaza autorii)
Network slicing in 5G permite operatorilor QoS diferit pentru clienti; 3GPP a introdus NWDAF in SBA, care colecteaza date din domeniile core si de management si face analitica pe date istorice. Automatizarea si managementul slice-urilor end-to-end in medii multi-domeniu este o sarcina critica (rezumat).

## Ce propun (metoda, pe scurt)
O platforma closed-loop Intent-based Networking (IBN) care asigura automat commissioning, activare, monitorizare la runtime si decommissioning al slice-urilor, integrata cu NWDAF pentru managementul ciclului de viata al slice-urilor e2e. Prin modele ML in NWDAF se prezic incarcarea slice-ului, mobilitatea utilizatorilor, prognoze de trafic si detectia de anomalii (rezumat).
