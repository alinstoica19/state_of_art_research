# Fault Root Cause Location based on Machine Learning in 5G Core Network (2024)

## Problema (cum o formuleaza autorii)
Odata cu virtualizarea 5GC, arhitectura e mai complexa si localizarea cauzei-radacina (RCL) a defectelor este dificila; O&M traditional bazat pe experienta manuala nu mai satisface cerintele.
## Ce propun (metoda, pe scurt)
Schema kNNBagging (k-nearest neighbor + Bagging): cauzele-radacina sunt deduse din ordine istorice de defecte, caracteristicile sunt extrase din baze de alarme, datele de alarma sunt pre-procesate; se compara kNN, Naive Bayes, SVM, kNN-NB-SVM (KNS), SVM-Bagging si kNNBagging.
