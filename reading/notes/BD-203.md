# Masked Transformer-based Multi-GAN for 5G Core Network KPI Anomaly Detection (2024)

## Problema (cum o formuleaza autorii)
Detectia anomaliilor in KPI-urile 5G core (5GC) este importanta pentru aplicatiile 5G; metodele existente bazate pe Generative Adversarial Networks (GAN) raman limitate (de exemplu pattern collapse).

## Ce propun (metoda, pe scurt)
MTMG, un model Masked Transformer-based Multi-GAN: Transformer pentru a invata asocierile dintre date, mai multi generatori si un discriminator pentru a evita pattern collapse, un mecanism de mascare pentru a invata distributia normala si a preveni degradarea modelului din cauza anomaliilor din setul de antrenare, plus o strategie de root cause pentru localizarea anomaliilor.
