# Collaborative Network Agents Enabled 6G Core Network Architecture (2026)
Cheie: BD-554 . DOI/link: 10.1109/iwcmc69287.2026.11579841 . Sursa textului: DOAR REZUMAT (Semantic Scholar API; text integral inchis, IEEE)
Sectiunea din plan: B . Tema: agentic 6G core
## Problema (cum o formuleaza autorii)
Desi unele studii propun integrarea AI Agent in arhitectura nucleului 6G (6GC), ramane deschisa intrebarea ce fel de arhitectura de agenti este mai potrivita pentru 6GC.
## Ce propun (metoda, pe scurt)
O arhitectura 6GC bazata pe sistem multi-agent (MAS), care tine cont de caracterul distribuit, latenta ultra-redusa, fiabilitatea ridicata si integrarea multi-element al 6GC; structura ierarhica pe trei straturi; este prezentat un flux de serviciu pentru un use case; designul vizeaza servicii bazate pe intentii cu eficienta si fiabilitate mai bune.
