# Research on Cross-Layer Alarm Association in 5G Core Network (2023)

## Problema (cum o formuleaza autorii)
Rezultat de identificare a alarmelor cauza-radacina este dificil cu metodele traditionale de O&M din cauza arhitecturii complexe a 5G core; biblioteca de reguli de asociere a alarmelor cross-layer pentru 5G core este incompleta.
## Ce propun (metoda, pe scurt)
Algoritm de minare a regulilor de asociere a alarmelor cross-layer, bazat pe OPTICS si weighted FP-growth: OPTICS genereaza un set de tranzactii de alarme corelate in timp; apoi se extrage un set corelat spatial pe baza topologiei pe trei straturi; weighted FP-growth genereaza regulile.
