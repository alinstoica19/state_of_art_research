## Problema (cum o formuleaza autorii)
Kubernetes HPA permite imbunatatirea Power Usage Effectiveness a data center-elor, dar fluxurile critice, precum elementele 5G User Plane, necesita scheme de protectie Nominal:Backup care nu sunt bine adaptate la HPA (rezumat).

## Ce propun (metoda, pe scurt)
Un framework de eficienta energetica pentru compararea a doua moduri de configurare a unui Horizontal Pod Autoscaler pentru o Virtual Network Function protejata N:1; include formulare analitica, curbe de decizie pentru ingineri si rezultate experimentale (rezumat).
