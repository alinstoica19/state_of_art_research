# Enabling Cloud-Native Observability for White-Box Performance Analysis of the 5G Core (2025)

## Problema (cum o formuleaza autorii)
Maturitatea tehnologiilor open-source 5G este considerata insuficienta pentru implementari la scara mare, performante. Metodologiile curente de testare a performantei 5G sunt predominant black-box si ignora interactiunile dintre componentele core-ului, limitand explicarea blocajelor de performanta.
## Ce propun (metoda, pe scurt)
O metodologie de testare a performantei core-ului 5G ghidata de observabilitate, cu (i) workload-uri de testare care simuleaza rate variabile de sosire a utilizatorilor si (ii) un set de unelte cloud-native de observabilitate pentru evaluare white-box.
