# Mosaic: A Cognitive Memory Orchestration Framework for GenAI-Assisted 5G-Advanced Network Operations (2026)
Cheie: BD-92 . DOI/link: 10.1109/infocom59046.2026.11571609 . Sursa textului: DOAR REZUMAT (Semantic Scholar API; textul integral e inchis, IEEE)
Sectiunea din plan: B . Tema: LLM agents / NWDAF / memory
## Problema (cum o formuleaza autorii)
Abordarile GenAI actuale functioneaza ca motoare de regasire fara stare: consuma analitica (NWDAF ofera semnale predictive) dar nu acumuleaza cunostinte operationale si nu mentin context intre sesiuni multi-turn; apare un "cognitive gap": agentii vad starea imediata dar nu au memorie pe termen lung pentru a contextualiza anomaliile fata de incercarile anterioare de remediere.
## Ce propun (metoda, pe scurt)
Mosaic, un cadru de orchestrare a memoriei cognitive care transforma LLM-uri fara stare in agenti operationali cu stare, printr-o ierarhie de memorie pe trei niveluri: Semantic Memory (Network Resource Models), Procedural Memory (SOP-uri/runbooks), Episodic Memory (lectii invatate cu consolidare bazata pe reflectie).
