# 5G Core Network Traffic Prediction Based on NWDAF Multi-Model Fusion (2024)

## Problema (cum o formuleaza autorii)
Accesul unui numar mare de dispozitive in 5G poate depasi constrangerile de resurse ale core-ului si afecta cererea utilizatorilor. Analiza si predictia traficului din core este necesara pentru optimizarea configuratiei, imbunatatirea QoS si reducerea costurilor, dar predictia precisa cu pastrarea confidentialitatii datelor este dificila din cauza diversitatii, complexitatii si sensibilitatii datelor.

## Ce propun (metoda, pe scurt)
NWDAF-MMF, un cadru de predictie a traficului prin fuziune de modele (inspirat de NWDAF si ensemble learning), in care NWDAF obtine datele de la NF-uri, reducand transmiterea si stocarea de date. Trei submodule: preprocesare (agregare, curatare, selectie de trasaturi, impartirea setului de date), antrenare si analiza multi-model (modele de baza si predictiile lor), fuziune multi-model (integrare, optimizare, iesire finala).
