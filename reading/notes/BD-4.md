# P-Cloud5GC: Innovative 5G Core Architecture on Public Cloud with Scalability and Fault Tolerance (2025)
Cheie: BD-4 . DOI/link: 10.1109/netsoft64993.2025.11080619 . Sursa textului: DOAR REZUMAT (OpenAlex; text integral inchis, IEEE)
Sectiunea din plan: B . Tema: cloud-native 5GC / fault tolerance
## Problema (cum o formuleaza autorii)
Cresterea retelelor mobile si nevoia de infrastructura rezilienta ridica provocari de scalabilitate si toleranta la defecte pentru mobile core network.
## Ce propun (metoda, pe scurt)
Premature-Cloud5GC (P-Cloud5GC), o arhitectura de 5G CN pentru medii de cloud public, care extinde designul serverless de control plane al Cloud5GC cu functionalitate de user plane si tehnologii de tip web-application, pentru scalabilitate, gestiunea sesiunilor si izolarea defectelor. Foloseste computing serverless, mesagerie distribuita si baze de date cloud-native si instantiaza un "micro Mobile Core" per procedura UE, pentru a preveni defectele de scara larga si a spori redundanta.
