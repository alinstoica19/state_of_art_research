# FlexCore: Leveraging XDP-SCTP for Scalable and Resilient Network Slice Service in Future 5G Core (2023)

## Problema (cum o formuleaza autorii)
Planul de control 5GC este partajat intre mai multe slice-uri dependente ale planului de date; pe masura ce cresc slice-urile si serviciile, creste amenintarea la adresa rezilientei.
## Ce propun (metoda, pe scurt)
FlexCore: 5GC flexibil, scalabil si rezilient pentru arhitecturi stateful si stateless. Foloseste un load balancer SCTP bazat pe XDP/eBPF la intrarea planului de control 3GPP-compliant si un set de instante micro-AMF; cererile sunt tratate per slice, per utilizator sau per procedura de control.
