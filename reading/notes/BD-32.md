# Data Characteristics Descriptor Based Model Transfer Architecture in 5G Core Network (2024)

## Problema (cum o formuleaza autorii)
In specificatiile curente, capacitatea NWDAF de a selecta modele sau network functions potrivite caracteristicilor sarcinii AI tinta este limitata, ceea ce poate reduce eficienta antrenarii si acuratetea modelelor in core-ul 5G.
## Ce propun (metoda, pe scurt)
O arhitectura de transfer de modele ML bazata pe un data characteristics descriptor, care ajuta NWDAF sa selecteze modele ML sau NF-uri membre adecvate sarcinii tinta. Lucrarea schiteaza arhitectura de baza si procedurile generale pentru scenarii de transfer learning si de selectie a membrilor in federated learning.
