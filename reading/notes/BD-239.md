# A Method to Improve the Performance of Network Data Analytics Function Based on Transfer Learning (2023)
Cheie: BD-239 . DOI/link: 10.1109/bmsb58369.2023.10211191 . Sursa textului: DOAR REZUMAT (OpenAlex/Crossref; IEEE BMSB 2023, text integral nedisponibil liber)

## Problema (cum o formuleaza autorii)
Imbunatatirea corectitudinii analiticii de retea este o problema cheie studiata in 3GPP Rel-18. Transfer learning este prezentat ca metoda de ML ce poate imbunatati performanta si eficienta antrenarii modelului unui task AI tinta.
## Ce propun (metoda, pe scurt)
O metoda de imbunatatire a performantei NWDAF inspirata din transfer learning. NWDAF stocheaza modelele ML antrenate in ADRF (Analytics Data Repository Function), iar ADRF inregistreaza informatiile despre model la NRF. Lucrarea descrie principiile, arhitectura sistemului, procedurile cheie si parametrii cheie ai metodei propuse de transfer de model.
