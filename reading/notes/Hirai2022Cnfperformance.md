## Problema (cum o formuleaza autorii)
Cloud-native Network Functions (CNF) vor fi folosite ca platforma pentru MEC si necesita desfasurare mai distribuita (de la edge la cloud privat sau public); numarul combinatiilor de resurse software si hardware creste, iar proiectarea resurselor hardware optime in functie de cerintele serviciilor devine dificila (rezumat).

## Ce propun (metoda, pe scurt)
Un motor automat de CNF provisioning care optimizeaza resursele hardware alocate CNF-urilor din perspectiva asigurarii performantei si minimizarii costului echipamentelor. Se foloseste machine learning pentru core-ul mobil 5G cloud-native, construind un model de predictie a performantei pentru functii de control plane si user plane in diverse conditii hardware, pe baza datelor de caracteristici de performanta de pe o platforma de test proprie (rezumat).
