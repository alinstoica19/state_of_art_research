# S1 subagent final report (gaps and communities)
Gaps vs 3GPP Rel-18-21:
1. No journal-grade NWDAF survey: only a magazine tutorial and short conference reviews; a systematic NWDAF/MDA review is a real gap.
2. MDA (TS 28.104) has almost no academic evaluation, nor MDA-NWDAF interplay, despite SA5 phases 2-4.
3. Standard data-collection/model-lifecycle machinery (DCCF, ADRF, MFAF, MTLF/AnLF split, accuracy monitoring) rarely used; drift handled outside standard procedures (exceptions: OAI model provisioning, MLflow closed loop).
4. Rel-19 topics (vertical FL AF-NWDAF, signalling-storm/abnormal-signalling analytics, trust/explainability) barely studied; FL papers mostly simulations.
5. Weak evaluation: synthetic/generic datasets (Milano, intrusion) or small free5GC/OAI/Open5GS labs, no operator data, almost none close the loop into control decisions. LLM/agentic NWDAF only appears in 2026.
Communities (rel-3): Western Univ. (Shami, Manias, Chouman) x3; EURECOM (Ksentini, Mekrache, Ameur, Brik; Härri) x3; Waterloo (Boutaba, Limam, Shafiei Ardestani); Ansari (NJIT); Granelli (Trento); Korean groups.
